### About Zano Wallet

**Zano Wallet** is the official desktop privacy wallet for the Zano ecosystem, built by Zano Wallet LLC under Zano Foundation contracts. It provides true self-custody and default financial privacy with no KYC and zero telemetry.

* **Untraceable by Default:** Ring signatures and stealth addresses ensure complete transaction confidentiality on-chain.
* **Confidential Assets:** Issue, transfer, and swap custom privacy tokens on the Zano blockchain.
* **Hybrid PoW / PoS Staking:** Earn staking rewards 24/7 directly from your desktop wallet balance.
* **Decentralized Aliases:** Replace complex cryptographic addresses with human-readable `@username` aliases.
* **Cross-Platform:** Available for Windows, macOS, and Linux *(mobile builds coming soon)*.
